# ChemLab – Chemie-Lernhub (GitHub Pages)

Eine kleine, responsive Lernwebsite für Klasse 9 mit Chemie-Themen Biogas, Methan und Alkane.

## Lokal testen
Öffne `index.html` im Browser. Für den lokalen Test werden keine Build-Tools benötigt.

## Auf GitHub Pages veröffentlichen
1. Erstelle auf GitHub ein neues Repository, z. B. `chemie-lab`.
2. Lade alle drei Website-Dateien (`index.html`, `style.css`, `script.js`) und diese README hoch (oder entpacke dieses ZIP und lade den Inhalt hoch).
3. Öffne im Repository **Settings → Pages**.
4. Bei **Build and deployment** wähle **Deploy from a branch**.
5. Wähle `main` und `/ (root)`, dann **Save**.
6. Nach dem Build wird die Website unter `https://DEIN-NAME.github.io/chemie-lab/` erreichbar (Repository-Name ggf. ersetzen).

Die Quiz-Funktion und Lernkarten laufen komplett im Browser; es gibt keinen Server und keine Datenerfassung.
